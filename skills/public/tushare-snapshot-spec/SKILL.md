# Tushare Pro 官方付费数据湖规约

本规约定义了 Data Agent（数据专员）处理真实 A 股数据时的硬性技术红线：

## 核心红线
1. **绝对禁止模拟数据**：
   - 严禁调用任何随机生成、正态分布采样或插值生成的假行情；
   - 必须基于经过指纹锁定的 Tushare Pro 付费快照（基准指纹 `4b139947`）。
2. **单位契约规范**：
   - Tushare 日线成交量 `vol` 单位为手，入库时必须强制转换：`volume_shares = vol * 100`；
   - 价格统一使用未复权原始 OHLC，严禁将复权价格送入资金回测。
3. **停牌与财务因果对齐**：
   - 缺失收盘价必须严格核对官方交易所停牌通告（`suspend_type='S'`），未核实的缺失不得标记为停牌；
   - 财务报表（利润表、资产负债表）严格依据公告日 `ann_date`（真实披露日）向前对齐，严禁使用财报报告期截止日 `end_date`。
